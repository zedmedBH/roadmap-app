1. Project Overview & Constraints
Purpose: A student self-pacing tracker and Learning Management System (LMS) tailored for the IB Middle Years Programme (MYP).
Hosting & Architecture: 100% Serverless. Hosted on GitHub Pages.
Tech Stack: React (TypeScript), Vite, React Router (using HashRouter), Tailwind CSS.
Backend / Database: Firebase (Google SSO Authentication, Firestore Database, Google Drive REST API for file/image storage).

2. Firestore Data Model & Security (RBAC)
Security Rules:
Strict RBAC implemented. Teachers have global write access to classes, groups, master banks, and course resources. Students only have write access to their own profile, their claimed timeline tasks, and their journal submissions. Student reads for course resources are restricted to items where their classId is in the visibleIn array. Reads require authentication.

Schema:
Classes: { id, name, teacherId, term, driveFolderId }
Users: { id, email, firstName, lastName, role: 'teacher' | 'student', classId, groupId, masterFolderId?, studentFolderId?, githubRepo? }
Groups: { id, name, classId, memberIds: string[] }
TaskTemplates (Master Bank): { id, title, color, taskType: 'team' | 'individual', subtasks: string[], isBroadcasted: boolean, dependencies: string[], rubricStrands: any[] } 
TimelineItems (Active Tasks): { id, templateId, title, group (userId or teamId), start_time, end_time, status, taskType, dependencies: string[], unclaimed: boolean, rubricStrands: any[] }
Submissions (Journal Entries): { id, timelineItemId, userId, textResponse, imageUrls: string[], timestamp, lastEdited }
Rubrics: { id, teacherId, criterion, strand, title, bands: Array<{levels, officialDescriptor, studentExemplar}> }
Feedback: { id, timelineItemId, userId, teacherId, scores: Record<string, number>, comment: string, updatedAt: number }
CourseResources (Static Files/Links): { id, teacherId, title, description, url, resourceType: 'link' | 'document' | 'video', visibleIn: string[], createdAt: number }

3. UI/UX Architecture & Routing
Navigation (<Navigation />): Global top bar handling Google SSO logout, dynamic Welcome messages, and a Teacher "View as Student" spoofing dropdown.

Teacher Dashboard: Tabbed interface hiding complex menus. Tabs include:
  1. Master Roadmap (TimelineView)
  2. Journal Grading (TeacherJournalReview)
  3. Task & Rubric Banks (TeacherTaskBank, TeacherRubricBank)
  4. Class Resources (TeacherResourceBank)
  5. Class Setup & Admin (ClassManagement, TeacherSettings, StudentRosterImport, GroupManagement)

Student Dashboard: Unified view containing a prominent "Open Journal" banner, their TimelineView, the StudentResourceHub, and the StudentTaskBank.

4. Development Roadmap & Implementation Status
Phase 1: Environment & Infrastructure (Completed)
React + Vite + TypeScript. HashRouter for gh-pages. Firebase SSO & Firestore integrated. RBAC secured.

Phase 2: Authentication & Class Management (Completed)
- TeacherSettings: Stores Google Drive Master Folder ID with a visual verification badge.
- StudentRosterImport: Real-time roster view allowing manual single-adds, bulk CSV imports (Papaparse), and instant student dropping.
- GroupManagement: Drag-and-drop UI (@dnd-kit/core) assigning students to project groups.

Phase 3: The Timeline UI (Planning Engine) (Completed)
- react-calendar-timeline integration.
- Teacher View: Broadcasts tasks globally.
- Student View: Unified view rendering a "Team" row and "Personal Tasks" row dynamically based on taskType. Students have full resize/move permissions over personal tasks; broadcasted tasks are locked.

Phase 4: Task Bank & Modals (Completed)
- TeacherTaskBank: Manage master tasks, cascade edits globally, and push new tasks via the embedded TaskPanel.
- StudentTaskBank: Browse un-broadcasted templates. Smart claiming enforces prerequisite dependencies before allowing a task to be added to the timeline.
- TaskSummaryModal: Allows students to check off subtasks, view rubrics, change status, and click an explicit "Open Engineering Journal" routing button.

Phase 5: MYP Assessment & Rubrics (Completed)
- TeacherRubricBank: Admin panel creating reusable Criteria A-D strands.
- Tasks embed these rubrics, capping max achievement bands directly in the TaskPanel.

Phase 6: The Engineering Journal (Execution Engine) (Completed)
- Editable GitHub Repo link stored on the user document.
- Dual-Mode Interface: Toggles between Edit Mode (continuous feed of active task forms) and Preview Mode (LaTeX aggregated markdown).
- File Uploads: Captures OAuth token to push image uploads to the Teacher's Master Drive Folder, storing the returned webViewLink in the submission.
- react-latex-next compiles mathematical formatting dynamically.

Phase 7: Assessment & Feedback (Completed)
- TeacherJournalReview: Select a student, view their GitHub link, and read compiled Preview documents.
- Interactive Grading: Teachers click rubric band boxes to lock in scores and leave comments, which sync to the Student's Preview Mode.

Phase 8: Static Class Resources (Completed)
- CourseResources Firestore schema established with class-specific visibility toggling.
- TeacherResourceBank: Full CRUD operations for global links and static materials.
- StudentResourceHub: Read-only grid filtering resources dynamically based on the student's assigned classId.
